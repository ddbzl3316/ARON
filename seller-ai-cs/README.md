# 셀러 AI 직원 (Seller AI CS) 🚀

온라인 셀러(도매몰, 스마트스토어, 쿠팡 등)를 위한 AI 기반 CS 및 리스크 관리 보조 대시보드입니다. 상품정보와 고객문의를 바탕으로 안전한 고객 발송용 CS 답변을 생성하고, 잠재적인 위험 문구를 필터링하여 1인 기업 및 셀러들의 업무 효율을 극대화합니다.

## ✨ 주요 기능
- **고객 발송용 CS 답변 생성**: 고객 친화적이면서도 판매자의 법적 리스크를 최소화하는 정제된 메신저형 답변 제공
- **위험문구 체크**: KC, 인증, 의료용, 과대광고 등 판매자가 놓치기 쉬운 주의사항 경고
- **상품 요약**: 긴 상품 정보에서 핵심만 요약
- **상품 DB 관리**: LocalStorage를 이용해 상품별로 생성 내역과 과거 문의를 자동 저장

## 🛠 기술 스택
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Lucide React (아이콘)

## 📦 초보자를 위한 설치 및 실행 가이드

1. **Node.js 설치 여부 확인**
   - 컴퓨터에 Node.js가 설치되어 있어야 합니다. (버전 18 이상 권장)

2. **프로젝트 열기**
   - 터미널을 열고 프로젝트 폴더로 이동합니다.
   ```bash
   cd seller-ai-cs
   ```

3. **패키지 설치**
   - 아래 명령어를 입력하여 필요한 라이브러리들을 설치합니다.
   ```bash
   npm install
   ```

4. **로컬 서버 실행**
   - 아래 명령어를 입력하면 로컬 웹 서버가 켜집니다.
   ```bash
   npm run dev
   ```

5. **웹 브라우저 접속**
   - 인터넷 브라우저를 열고 주소창에 \`http://localhost:3000\`을 입력하여 접속합니다.

## 🤖 실제 OpenAI 연동 가이드 (강력 추천)
현재 기본적으로 모의 응답(Mock AI)이 작동하지만, OpenAI API 키를 발급받아 연결하면 실제 AI가 구동됩니다.

1. 프로젝트 폴더 최상단(`seller-ai-cs/`)에 `.env.local` 이라는 이름의 새 파일을 생성합니다.
2. 아래와 같이 API 키와 모델을 작성합니다. (주의: 따옴표 없이 입력)
   ```env
   OPENAI_API_KEY=sk-본인의_오픈AI_API_키를_여기에_붙여넣기
   OPENAI_MODEL=gpt-4o-mini
   ```
3. 파일을 저장한 후 서버를 껐다가 다시 켭니다 (`npm run dev`).
4. 이제 화면에서 버튼을 누르면 실제 OpenAI 모델이 실시간으로 고품질의 CS 답변과 상품 분석을 생성해냅니다!

*※ API 키가 만료되거나 호출에 실패하더라도 사이트가 멈추지 않고, 자동으로 안전한 모의(Mock) 응답을 반환하도록 이중 설계되어 있습니다. 안심하고 사용하세요.*
